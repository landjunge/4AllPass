# Websites in this worktree

When building or restyling **web pages** (landing, hub, PWA chrome, HTML/CSS, marketing):

1. Read `.grok/skills/frontend-design/SKILL.md` first (distinctive visual direction).
2. Then `.grok/skills/web-design-guidelines/SKILL.md` (accessibility, UX, review).
3. For React/PWA UI: `.grok/skills/vercel-react-best-practices/SKILL.md`.
4. Keep product trees isolated: landing `4allpass.netzwerkpunkt.de` is static (no `/api`). Vault is `vault.4allpass.netzwerkpunkt.de`. See `deploy/LAYOUT.md`.
5. DE und EN on every user-facing surface. 4AllPass landing uses Golden Magpie (`docs/DESIGN.md`), not Gnom-Hub-Grau.
