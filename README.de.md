## Sicherheitshinweis

**Version 0.1.2-rc.3:** Der Maschinenzugriff ist gesperrt; Anfragen werden auch nach „Erlauben“ abgelehnt. Bei Version 0.1.2-rc.2 und älteren Vorabversionen konnte ein erlaubter Maschinenzugriff gespeicherte Geheimnisse an verbundene Programme weitergeben. Wer diesen Zugriff erlaubt hat, sollte betroffene Zugangsdaten beim jeweiligen Anbieter ändern oder widerrufen. Ein Update kann bereits weitergegebene Geheimnisse nicht zurückholen.

[Details zum Sicherheitsproblem](docs/release-notes/0.1.2-rc.2-security-notice.md)
