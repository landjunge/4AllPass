> [!WARNING]
> **Sicherheitshinweis: Maschinenzugriff gibt in dieser Version echte Geheimnisse heraus.**
>
> **Was:** In 0.1.2-rc.2 gibt der Maschinenzugriff nach einem Klick auf
> „Erlauben“ das echte gespeicherte Geheimnis (zum Beispiel ein Passwort oder
> einen Zugangsschlüssel) als `access_token` an das anfragende Programm weiter.
> Es ist kein neuer, eingeschränkter Schlüssel, sondern eine Kopie des
> Tresorinhalts. Die Zeitbegrenzung holt diese Kopie nicht zurück.
>
> **Wer ist betroffen:** Nur wer in 0.1.2-rc.2 (oder einer älteren Vorabversion)
> ein Programm mit 4AllPass verbunden und eine Zugriffsanfrage mit „Erlauben“
> bestätigt hat. Tresor, Import, Autofill, Recovery und Verschlüsselung sind von
> diesem Hinweis nicht betroffen.
>
> **Empfehlung:**
> 1. In dieser Version keinem Programm „Erlauben“ geben und keine Programme neu verbinden.
> 2. Jeden Zugang, der so freigegeben wurde, beim jeweiligen Anbieter ändern oder widerrufen.
> 3. Auf die nächste geprüfte Version warten. Im aktuellen Quellstand ist dieser
>    Weg gesperrt; jede Anfrage wird abgelehnt, auch nach „Erlauben“.
>
> ---
>
> **Security notice: machine access discloses actual secrets in this version.**
>
> **What:** In 0.1.2-rc.2, after you click "Allow", machine access passes the
> actual stored secret (for example a password or an access key) to the
> requesting program as `access_token`. It is not a new, scoped key but a copy
> of vault content. The time limit cannot recall that copy.
>
> **Who is affected:** Only users who connected a program to 4AllPass in
> 0.1.2-rc.2 (or an older preview) and confirmed an access request with "Allow".
> Vault, import, autofill, recovery and encryption are not affected by this notice.
>
> **Recommendation:**
> 1. Do not click "Allow" for programs in this version and do not connect new programs.
> 2. Change or revoke every credential released this way at its provider.
> 3. Wait for the next verified version. Current source blocks this path; every
>    request is denied, including after "Allow".
