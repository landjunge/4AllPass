4AllPass

Selbst gehosteter Zero-Knowledge-Passwortmanager.
Deine Agenten brauchen Zugang. Nicht deine Secrets.

GitHub (Quelle) Zwei-Minuten-Demo Launch-Notiz

Für Self-Hoster und Leute, die n8n oder KI-Agenten betreiben und keine langlebigen API-Keys im Workflow parken wollen.

git clone https://github.com/landjunge/4AllPass.git
cd 4AllPass
docker compose up --build

Startet Postgres, Redis und das Backend auf http://localhost:8000. Vault in der PWA entsperren, dann den Access-Tab öffnen. FastAPI gibt keine Tokens aus. Es gibt keinen n8n-Marketplace-Node.
