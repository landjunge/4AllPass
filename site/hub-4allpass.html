4AllPass

Ein digitaler Tresor, der wirklich dir gehört.

Ich gehe auf eine Seite — 4AllPass erledigt den Login.

Desktop laden GitHub Dokumentation

Zuverlässiges Autofill

Import aus dem Browser, Review ohne Passwort in der Liste, dann Login ohne Copy-Paste.

Zero-Knowledge

Argon2id, AES-256-GCM. Vault Key pure random. FastAPI mintet keine Tokens.

Agenten kontrolliert

Allow/Deny + TTL. Nie erster Bildschirm, nie den ganzen Tresor.

Was ist es

4AllPass ist ein lokaler Passwort-Tresor. Das Produkt ist die Desktop-App (Tauri + SQLite). Agenten nur nach explizitem Allow/Deny + TTL.

Warum

Zuerst muss Autofill im Alltag funktionieren — dann kann daraus eine Vertrauensinfrastruktur werden. Vision: Daniel Filipek (landjunge).
