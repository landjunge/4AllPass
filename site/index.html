4AllPass

Self-hosted zero-knowledge password manager.
Your agents need access. They don't need your secrets.

GitHub (source) Two-minute demo Launch note

For self-hosters and people who run n8n or AI agents and do not want long-lived API keys sitting in a workflow.

git clone https://github.com/landjunge/4AllPass.git
cd 4AllPass
docker compose up --build

Starts Postgres, Redis, and the backend on http://localhost:8000. Unlock a vault in the PWA, then open the Access tab. FastAPI never mints tokens. There is no n8n marketplace node.
