Passwort-Tresor · Zero-Knowledge · Desktop first

Ein digitaler Tresor, der wirklich dir gehört.

Bei den meisten Passwort-Apps speichert eine Firma deine Daten in der Cloud. Bei 4AllPass kann der Server deine Passwörter nicht lesen. Alles Wichtige liegt bei dir auf dem Gerät.

With most password apps a company stores your data in the cloud. With 4AllPass the server cannot read your passwords. What matters stays on your device.

Das Produkt ist die Desktop-App. Du installierst sie, legst einen Tresor an, importierst Passwörter aus dem Browser — und ab dann erledigt 4AllPass den Login.

The product is the desktop app. Install it, create a vault, import from the browser — then 4AllPass handles the login.

Installieren→Importieren→Autofill→fertig

Desktop laden Quellcode Produktseite

macOS-Builds sind derzeit ad-hoc (nicht notariert): Rechtsklick → Öffnen, oder der One-Liner unten. Unlock = Tresor-Passwort. Ohne Recovery-Kit kein Zurücksetzen.

macOS builds are ad-hoc (not notarized): right-click → Open, or the one-liner below. Unlock = vault password. No recovery kit means no reset.

Zuverlässiges Autofill

Das, was du wirklich willst: Seite öffnen, Login erledigt. Field Intelligence + Safe Fill. Browser-Import mit Review — Passwörter erscheinen nie in der Liste.

Zero-Knowledge

Argon2id, AES-256-GCM. Vault Key ist pure random, nie aus dem Master-Passwort abgeleitet. FastAPI mintet keine Tokens. Der Server ist Blob-Store.

Agenten unter Kontrolle

n8n und KI-Tools bekommen Zugang nur nach explizitem Allow/Deny + TTL — nie als ersten Bildschirm, nie den ganzen Tresor. Loopback-Broker.

Was wir bewusst nicht machen

Fundament zuerst

Kein Blockchain, keine eigene digitale Identität, keine 20 Zukunftsfeatures auf einmal. Zuerst muss 4AllPass im Alltag einfach und vertrauenswürdig sein. Dann kann daraus mehr werden — genau so, wie die Produktvision von Daniel Filipek (landjunge) vorsieht.

curl -fsSL https://raw.githubusercontent.com/landjunge/4AllPass/main/scripts/install.sh | sh

Installer pinnt GitHub-Tag desktop und prüft SHA-256. Vault-Ordner bleibt. Ohne Pipe: Script speichern, lesen, sh install.sh. Windows: irm https://raw.githubusercontent.com/landjunge/4AllPass/main/scripts/install.ps1 | iex.

The installer pins GitHub tag desktop and checks SHA-256. The vault folder is never deleted. Without a pipe: save, read, sh install.sh.
