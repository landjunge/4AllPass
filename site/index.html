Credentials · Zero-Knowledge

Agents brauchen Zugang. Nicht deine Secrets.

Lokaler Passwort-Tresor. Import, Autofill, Zero-Knowledge. Der Server sieht keinen Klartext. FastAPI gibt keine Tokens aus.

Autonome Agents brauchen Credentials, ohne den Tresor zu besitzen. Richtlinie entscheidet, Zugang ist zeitlich begrenzt, Geräte halten die Schlüssel.

Produktseite GitHub 4allpass.netzwerkpunkt.de

Zero-Knowledge

Argon2id, AES-256-GCM, WebAuthn-PRF. Vault Key ist random, nie aus dem Master-Passwort abgeleitet.

Agent Access

Anfrage → Richtlinie → erlauben oder ablehnen → zeitlich begrenzter Zugang. SDK: @4allpass/access.

Desktop first

Tauri-App, SQLite lokal. Launch at login entsperrt den Tresor nicht.
